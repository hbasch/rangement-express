# Rangement Express

Simulateur 3D pour apprendre le rangement des engins de secours (VSAV, FPT) et des véhicules d'intervention, directement dans le navigateur.

- Entraînement chronométré : trouver un objet, désigner le bon coffre, repérer ce qui manque, départ en intervention.
- Édition de ses propres engins, coffres et départs types.
- QR codes par coffre et lien de partage d'un engin.

Aucun compte, aucun serveur, aucune donnée collectée : tout reste dans le navigateur de l'utilisateur.
